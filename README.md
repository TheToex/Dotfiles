### shotcuts
**main mod is SUPER**
- SUPER + RETURN = rofi applauncher
- SUPER + T = kitty terminal
- SUPER + A = rofi Theme selector
- SUPER + F = open filemanager 
- SUPER + Esc = rofi logout menu
- SUPER + F11 = fullscreen current window
- SUPER + Prtsc = screenshot (copy on your clipboard)
- SHIFT + Prtsc = screenshot (save in ~/Pictures/screenshots)
- SUPER + F7 = screenrecorde (via wf-recorder)
- SHIFT + F7 = stop screenrecorder
for more shortcuts, please see **~/.config/hypr/hyprland.conf**
